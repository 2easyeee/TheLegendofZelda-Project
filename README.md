# 젤다의 전설:꿈꾸는 섬

개인 프로젝트로 진행한 던전 탐험, 퍼즐, 실시간 전투 요소를 가진 3D 액션 어드벤처 모작 프로젝트입니다.

이 저장소는 포트폴리오에 소개된 주요 기능의 소스 코드를 공개하기 위해 정리한 공개용 저장소입니다.

## 프로젝트 정보

- 개발 기간: 2026.01 - 2026.03
- 담당 역할: Engine / Client / Editor
- 개발 인원: 1명
- 개발 환경: C++, DirectX11

## 저장소 구성

| 폴더 | 내용 |
| :--- | :--- |
| [Client](Client) | 플레이어, 몬스터, 전투, 상호작용 및 UI |
| [Engine](Engine) | 렌더링, 충돌, Navigation, 애니메이션 및 공통 시스템 |
| [MapTool](MapTool) | 콘텐츠 제작·편집 및 데이터 변환 도구 |
